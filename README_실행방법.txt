MEET PICK (밋픽) 실행 방법
==========================

뚜벅이들의 모임 장소 PICK: 참여자들의 출발지로 모두에게 공평한 모임 지역과 장소를 추천하는 서비스입니다.

[필요한 것]
- Windows PC, 인터넷 연결
- Python 3.11 이상 (없으면 https://www.python.org/downloads/ 에서 설치. 설치 첫 화면의 "Add python.exe to PATH" 체크)
- 키 파일(.env): 작성자에게 받은 API 키가 들어 있는 파일입니다.

[실행]
(키가 이미 들어 있는 "키포함" 압축이라면 2번은 건너뛰고, 더블클릭만 하면 브라우저가 저절로 열립니다.)
1. 압축을 풀고 "실행하기.bat"을 더블클릭합니다.
2. 처음 한 번: .env 파일이 없으면 자동으로 만들어 메모장이 열립니다. 받은 키를 채우고 저장한 뒤 창에서 아무 키나 누르세요.
   (받은 .env 파일이 있다면 이 폴더(실행하기.bat 옆)에 그대로 넣어 두면 이 단계는 건너뜁니다)
3. 처음 한 번: 필요한 프로그램이 자동 설치됩니다 (1~3분).
4. 브라우저가 열리면 http://localhost:5173 에서 서비스를 쓸 수 있습니다. 이 검은 창을 닫으면 종료됩니다.

[사용법]
- "로그인 없이 둘러보기"를 누르고, 참여자 이름과 출발지(예: 홍대입구역, 잠실역)를 입력한 뒤 모임 목적을 고르고 "추천 받기"를 누릅니다.
- 결과 화면에서 지역 탭, 참여자별 경로(경로 보기), 추천 장소, 카카오톡 공유를 볼 수 있습니다.
- 카카오 로그인·공유·지도는 키를 등록한 주소(localhost:5173)에서만 동작합니다. 다른 포트로 바꾸면 지도가 안 보일 수 있습니다.

[폴더 설명]
- backend/   서버(FastAPI) 코드: 추천 점수 계산(app/scoring), 경로·장소 연동(app/providers, app/services), 설정(config)
- frontend/  화면(React) 소스와 빌드 결과(dist)
- docs/evaluation/  평가 문서(기존 방식과의 비교 실험, 가중치 민감도, 점수 계산 근거, 사용자 평가 계획, 설문지)
- 실행하기.bat  더블클릭 실행

[자주 겪는 문제]
- 검은 창이 바로 닫힘 / "Python이 없다": Python 설치 후 다시 실행하세요.
- 지도가 안 뜸: .env의 VITE_KAKAO_JS_KEY와 카카오 개발자 콘솔의 웹 도메인(http://localhost:5173) 등록을 확인하세요.
- 출발지 검색이 안 됨: .env의 KAKAO_REST_API_KEY를 확인하세요.
- "이미 사용 중인 포트": 이미 켜져 있는 MEET PICK 창을 닫거나, 다른 프로그램이 5173을 쓰고 있는지 확인하세요.
- 처음부터 다시 설치: ".venv" 폴더를 지우고 다시 실행하세요.

[키와 보안]
- .env 파일에는 개인 API 키가 들어 있으니 다른 사람에게 전달하거나 인터넷에 올리지 마세요.
- 이 서비스는 서버를 내 PC(127.0.0.1)에서만 열어 외부에서는 접속할 수 없습니다.
