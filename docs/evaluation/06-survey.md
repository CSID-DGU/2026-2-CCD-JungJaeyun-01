# 설문지

**설문 페이지(축약판)**: `docs/evaluation/survey/survey.html`을 웹 페이지로 게시해 두었다 (게시 주소는 운영자가 공유 설정에서 공개 범위를 정해 응답자에게 보낸다). 아래 문항 중 B~F 핵심 문항만 3~5분 분량으로 넣었고, 슬라이더·버튼으로 답한다. 구글폼으로 옮겨도 되도록 전체 문항은 아래에 그대로 적어 둔다.

응답을 받는 방법은 세 가지다. **응답자가 가장 편한 것은 구글폼(방법 A)이다.**

**A. 구글폼 (추천: 응답자는 링크만 열면 된다)**
1. https://script.google.com 에서 새 프로젝트를 만들고 `docs/evaluation/survey/create_google_form.gs` 내용을 붙여넣는다.
2. `createSurvey` 를 실행한다 (처음 한 번 구글 계정 권한 허용). 실행 로그에 응답자용 링크와 응답이 쌓이는 시트 주소가 나온다.
3. 응답이 모이면 시트에서 파일 → 다운로드 → CSV로 받아 변환·분석한다.

```bash
cd backend
python scripts/survey_to_csv.py 받은파일.csv -o 응답.csv   # 구글 시트 CSV → 분석용 CSV
python scripts/analyze_survey.py 응답.csv                  # 가중치 계산
```

**B. 설문 웹 페이지(`survey.html`)**: 응답 저장 권한이 있는 사람이 제출하면 페이지 저장소(`responses`)에 쌓인다. 읽기 전용으로 연 응답자는 제출 후 **응답 코드(`MP1.…`)** 가 나오고, 코드를 메시지로 받아 한 줄에 하나씩 `codes.txt`에 모은 뒤 `survey_to_csv.py codes.txt -o 응답.csv`로 변환한다.

**C. 직접 입력**: 구글폼과 같은 문항으로 종이·메신저로 받은 응답은 `responses_template.csv`의 열에 맞춰 입력한다.

선택지 문구(예: "평균 이동시간이 훨씬 더 중요해요")는 `create_google_form.gs`와 `survey_to_csv.py`가 같은 문구를 쓴다. 한쪽만 바꾸면 응답을 읽지 못하므로 `tests/test_survey_script.py`가 두 파일이 맞는지 검사한다.

저장소에 쌓인 응답은 JSON 파일로 내려받은 폴더도 `survey_to_csv.py`가 같은 방식으로 읽는다. 응답에는 이름·위치가 없고(연령대·의견은 선택), 응답 CSV는 저장소에 올리지 않는다.


목적: 추천 점수의 가중치를 설계자의 임의값이 아니라 사용자 응답으로 정한다. 응답 CSV는 `scripts/analyze_survey.py`가 읽는다 (열 이름은 마지막 절 참고). 소요 시간은 약 5분이다.

## 안내 문구 (맨 위)

> 친구들과 약속 장소를 정할 때 "어디서 만나면 좋을지"를 추천해 주는 서비스를 만들고 있어요. 참여자들이 각자 출발해서 모임 지역까지 가는 **대중교통 이동시간**을 어떻게 평가해야 하는지, 그리고 **장소**를 고를 때 무엇이 중요한지 알려 주세요. 정답은 없고 응답은 익명으로 통계에만 쓰여요. 중간에 그만두셔도 돼요.

## A. 응답자 정보 (익명 코드는 운영자가 부여)

- A1. 연령대: 10대 / 20대 / 30대 / 40대 / 50대 이상
- A2. 한 달에 약속(친구 모임)을 몇 번 하나요? 0~1 / 2~3 / 4~7 / 8 이상
- A3. 약속에 주로 쓰는 교통수단: 지하철·버스 / 자차 / 도보·자전거 / 기타

## B. 이동시간 지표 쌍대비교 (AHP)

**먼저 예시를 읽어 주세요.** 세 명이 한 장소에서 만난다고 할 때 이동시간(분)입니다.

| | 사람 1 | 사람 2 | 사람 3 | 평균 | 최대 | 편차(들쭉날쭉한 정도) |
|---|---|---|---|---|---|---|
| 장소 X | 10 | 10 | 50 | 23 | 50 | 큼 |
| 장소 Y | 28 | 30 | 32 | 30 | 32 | 작음 |

- **평균**: 모두의 이동시간 평균 (짧을수록 좋음)
- **최대**: 가장 오래 걸리는 사람의 시간 (짧을수록 좋음)
- **편차**: 사람마다 걸리는 시간이 얼마나 다른가 (작을수록 공평)

각 질문에서 "어느 쪽이 더 중요한가"와 "얼마나 더"를 골라 주세요. 척도: **1 = 같다 / 3 = 약간 더 / 5 = 꽤 더 / 7 = 훨씬 더 / 9 = 압도적으로 더**

- B1. **평균** vs **최대**: 어느 쪽이 더 중요한가요? (왼쪽=평균 / 오른쪽=최대) + 정도(1·3·5·7·9)
- B2. **평균** vs **편차**: 같은 방식
- B3. **최대** vs **편차**: 같은 방식

> 구글폼으로 옮길 때는 "평균이 더 중요 9 … 3 / 같다 1 / 최대가 더 중요 3 … 9"처럼 한 줄 척도(17칸)로 만들면 쉽다. 입력값은 `analyze_survey.py`가 읽는 비율로 바꾼다 (평균이 3배 더 중요 → 3, 최대가 3배 더 중요 → 0.333).

## C. 이동시간 지표 100점 배분

- C1. 이동 평가에서 **평균 / 최대 / 편차** 세 가지에 합계 **100점**을 나눠 주세요. (예: 50 / 30 / 20)  — 합이 100이 아니면 제출되지 않게 설정

## D. 장소 요소 100점 배분

- D1. 약속 장소(식당·카페)를 고를 때 중요한 정도를 **다섯 가지에 합계 100점**으로 나눠 주세요.
  1. 역에서 가까운 정도(접근성)
  2. 평점
  3. 리뷰가 많은 정도(인기)
  4. 모임 목적에 맞는 종류(예: 식사 모임이면 음식점)
  5. 우리 연령대가 좋아하는 종류

## E. 시나리오 선택 (가중치 검증용)

같은 세 사람이 모일 때, 두 장소 중 어디로 가겠습니까?

| | 사람 1 | 사람 2 | 사람 3 |
|---|---|---|---|
| 장소 P | 15분 | 15분 | 45분 |
| 장소 Q | 28분 | 30분 | 32분 |

- E1. P / Q 중 선택 (P는 평균이 짧고 한 명이 오래 걸림, Q는 평균이 조금 길지만 모두 비슷함)
- E2. (사람이 5명인 비슷한 예) 선택 + 이유 한 줄
- E3. 지금 서비스의 기준(평균 40% · 최대 30% · 편차 30%)이 직관과 맞다고 느끼나요? 1~5

## F. 공평함 vs 장소 (충돌 규칙 조정용)

- F1. A 지역은 모두가 비슷하게(차이 3분) 도착하고 장소 평점이 보통이에요. B 지역은 이동이 한 사람만 **10분** 더 걸리지만 장소가 훨씬 좋아요. 어디로 가겠어요? A / B
- F2. 장소가 훨씬 좋다면 **이동이 몇 분까지 더 걸려도** 괜찮은가요? 0 / 5 / 10 / 15 / 20분 이상
- F3. 서비스가 "가장 공평한 곳"과 "공평함은 비슷하고 장소가 좋은 곳"을 **둘 다 보여주는 것**이 도움이 되나요? 1~5

## 응답 CSV 열 이름 (`analyze_survey.py` 입력)

| 열 | 뜻 |
|---|---|
| `respondent_id` | 익명 코드 |
| `ahp_avg_vs_max`, `ahp_avg_vs_std`, `ahp_max_vs_std` | B1~B3. 왼쪽 항목이 오른쪽보다 몇 배 중요한가 (1/9 ~ 9, 같으면 1) |
| `cs_avg`, `cs_max`, `cs_std` | C1 점수 |
| `ps_access`, `ps_rating`, `ps_popularity`, `ps_purpose`, `ps_age` | D1 점수 |
| `f2_extra_minutes` | F2에서 고른 분 |

빈 양식: `docs/evaluation/survey/responses_template.csv` (머리글만 있다. **실제 응답은 저장소에 올리지 않는다**).
