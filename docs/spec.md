# 맞춤형 모임 장소 추천 웹서비스

## 1. 프로젝트 개요
프로젝트명: 이동 편의성과 연령대별 트렌드를 고려한 맞춤형 모임 장소 추천 서비스

개발 목적: 여러 사용자의 출발지와 모임 조건을 입력받아, 참여자 간 이동시간과 이동 부담의 형평성을 고려한 최적의 모임 지역을 선정하고, 해당 지역 내에서 모임 목적 및 사용자 특성에 적합한 장소를 추천하는 웹서비스

핵심 차별점
- 단순 지리적 중간 지점이 아닌 실제 대중교통 이동시간 기반 추천
- 전체 이동시간뿐 아니라 참여자별 이동시간 편차를 고려한 공정성 평가
- 모임 목적, 연령대, 장소 평점 및 리뷰 등을 종합한 맞춤형 장소 추천
- 추천 결과와 선정 근거를 사용자가 이해할 수 있도록 시각화

## 2. 주요 기능

### ① 모임 조건 입력
- 참여자별 출발지 검색 및 입력 (최소 2명, 최대 5명), 주소 자동완성
- 참여자별 연령대 선택 (10대~50대 이상)
- 모임 목적 선택 (식사, 카페, 술자리 등)
- 이동수단: MVP는 대중교통 중심
- 추천 실행 버튼

### ② 이동시간 기반 최적 지역 추천
- 참여자별 출발지에서 후보 지역까지 대중교통 이동시간 계산
- 지하철역 또는 주요 상권 중심으로 후보 지역 선정
- 참여자별 평균 이동시간, 최대 이동시간, 이동시간 편차 산출
- RegionScore 계산 후 상위 3개 지역 추천
- RegionScore = 평균 이동시간(효율성) + 최대 이동시간(과도한 부담 방지) + 이동시간 편차(공정성)를 각각 정규화 후 가중치 적용. 가중치는 수정 가능하게 구현

### ③ 지역별 장소 추천
- 추천 지역 내 음식점, 카페, 주점 검색
- 이름, 주소, 카테고리, 평점, 리뷰 수 등 수집 가능한 정보 표시
- 모임 목적에 따른 분류 및 필터링
- 접근성, 평점, 리뷰, 목적 적합성을 종합한 PlaceScore 산출
- 지역별 상위 3~5개 장소 제공
- 평점·리뷰는 API별 제공 여부가 다르므로 확보 가능성 확인 필요

### ④ 연령대별 트렌드 반영
- 참여자 연령대에 따른 장소 추천 가중치 적용
- 네이버 데이터랩 등 외부 데이터 활용 검토
- 데이터 확보가 어려우면 사전 정의된 선호도 가중치로 대체
- 실제 데이터 기반 추천과 임의 가중치 기반 추천은 구분하여 구현

### ⑤ 지도 시각화
- 카카오맵 기반 지도
- 참여자 출발지, 추천 지역, 추천 장소 마커
- 지역별 이동시간 비교, 장소 상세 정보, 외부 지도 링크

### ⑥ 추천 결과 비교 및 설명
- 상위 3개 지역 순위, 참여자별/평균/최대 이동시간 표시
- 지역 선정 이유 및 장소별 주요 선정 기준 표시
- 지역·장소 비교 화면

## 3. 이용 흐름
접속 → 참여자 수·출발지 입력 → 연령대·목적 설정 → 추천 실행 → 상위 3개 지역 → 지역별 장소 및 지도 → 상세 정보 비교

## 4. 기술 스택
- 프론트엔드: React (Vite + TypeScript)
- 백엔드: Python FastAPI
- 지도: 카카오맵 API
- 대중교통 경로: ODsay API
- 장소 검색: 카카오 로컬 API
- 저장: 필요 시 SQLite

## 5. 우선순위
필수: 조건 입력, 대중교통 이동시간 계산, RegionScore 지역 추천, PlaceScore 장소 추천, 지도 시각화 및 비교
추가: 연령대 트렌드 자동 연동, LLM 리뷰 요약, 결과 공유, 사용자 선호 저장

## 6. 최종 산출물
실행 가능한 웹서비스, 전체 소스코드(GitHub 업로드 구조), 알고리즘 코드 및 점수 기준, API·환경변수 설정 방법, 로컬 실행 및 배포 문서, 기능 테스트 결과, 배포 URL, 보고서용 시스템 구조도·알고리즘 설명
